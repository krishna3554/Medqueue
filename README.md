# MedQueueAI

A responsive staff-facing prototype for an explainable, severity-aware OPD queue. It presents a live priority list, a high-visibility red-flag escalation, a patient-level explanation, vitals, and an auditable clinical-priority override flow.

## Run locally

```bash
npm install
npm run dev
```

Build a production bundle with:

```bash
npm run build
```

## Safety note

This interface is a design prototype for clinical decision support. It is not a diagnostic tool; production triage logic and red-flag rules require clinical review.
